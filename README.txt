XTION JERRY WEBSITE - QUICK START

1. Open index.html in a browser to preview the website.
2. Replace the placeholder music/video links in index.html.
3. Add more photos to the images folder and add them to the Gallery.
4. Replace your-email@example.com with your real booking/contact email.
5. To publish for free, upload these files to a GitHub repository and enable GitHub Pages.
6. Later you can connect a custom domain such as xtionjerry.com.

Files:
- index.html = website content
- style.css = design
- script.js = menu interaction
- images/xtion-jerry-hero.jpg = your main artist photo
